## Reproduction

Run the export scripts with the adjacent ScoreQuant Python environment. Override source checkouts
with `SCOREQUANT_REPO`, `ATLAS_REPO`, `RADAR_REPO` if needed. Import media from `src/assets/` so Vite
rewrites URLs under `/models-in-the-wild/`.

## Live-demo fallback

(profile onboarding otherwise appears), existing screenshot and bundled audio. No remote iframe
or model endpoint is needed for the presentation itself.
